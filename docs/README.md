# docs/ — Documentación de proyecto (post-demo)

Esta carpeta contiene la documentación técnica, de calidad y de cliente que
se decidió construir después de la primera demo con cliente. El roadmap
completo, con fases y orden de ejecución, está en **[`PROJECT_PLAN.md`](PROJECT_PLAN.md)**.

No confundir con la documentación operativa del día a día, que sigue
viviendo en la raíz del repo:
- `README.md` — instalación, arranque, variables de entorno, backups, recuperación de contraseña.
- `CLAUDE.md` — reglas y contexto de trabajo para Claude/Cowork en este repo.

## Estructura

- **`arquitectura/`** — documentación técnica del diseño actual (Línea 1 del plan).
- **`calidad/`** — plan de pruebas funcionales, de carga/concurrencia y checklist de seguridad (Línea 2).
- **`cliente/`** — resumen ejecutivo y anexo técnico para presentar a clientes (Línea 3).

Cada subcarpeta tiene un `README.md` corto que indica qué falta y en qué
fase del `PROJECT_PLAN.md` se produce.
